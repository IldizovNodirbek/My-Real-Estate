# Real Estate Company Website

## Project Description

Real Estate Company website is a professional, modern and responsive website designed for a real estate services company. The site allows users to obtain information about various real estate services and companies.

This site is built using modern technologies such as `React`, `Tailwind CSS`. The site is fully responsive in mobile and desktop versions.

## Key Features

- **Responsive design**: The site adapts to all screen sizes (from mobile phones to desktop screens).
- **Navigation menus**: Users have easy access to sections like "Home", "Features", "Clients", "About Us", "Contact Us"..
- **Footer department**: A footer filled with a brief company information, list of services, and links to social networks.
- **Services**: List of services offering real estate, commercial property, property management and investments.

## Technologies

- **Frontend**: 
  - `React` - for component structure and UI interactivity.
  - `Tailwind CSS` - + Responsive design for quick and easy styling
  
  
- **Resources**:
  - Real estate information and services.
  - Social networks: Facebook, Instagram, LinkedIn.
